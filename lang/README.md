# The WTF language

- `src/` — the crate, layered bottom-up; see the module docs in `src/lib.rs`.
- `stdlib/` — the bundled `.wtf` feature modules; see [stdlib/README.md](stdlib/README.md).
- `tests/` — the snapshot suite, which is the whole test suite; see [tests/README.md](tests/README.md).
- `examples/` — one short note per feature; see [examples/README.md](examples/README.md).
- `renderer/` — the HTML serializer shared by the CLI and the browser host.
